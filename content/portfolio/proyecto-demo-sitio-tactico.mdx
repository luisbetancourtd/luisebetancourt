## El Problema

El cliente necesitaba un sitio web que funcionara como **centro de operaciones digital** — no solo una landing page, sino un sistema completo de contenido documentando su camino migratorio y profesional.

## La Solución

Construimos un sitio estático con **Next.js 16 App Router** usando el patrón SSG (Static Site Generation). El contenido se maneja completamente desde **Tina CMS** sin necesidad de tocar código.

### Stack técnico
- **Next.js 16** con Turbopack para builds rápidos
- **Tailwind CSS v4** con diseño Tactical Brutalism (no-radius, high contrast)
- **Tina CMS** integrado como CMS git-based para posts, páginas y portafolio
- **Framer Motion** para animaciones de entrada y micro-interacciones
- **lucide-react** para iconografía profesional sin emojis ni unicode

## Resultados

- **Build completo en ~6 segundos** con Turbopack
- **100% estático** — deploy a Vercel sin servidor
- **Contenido 100% editable** desde Tina CMS sin conocimientos técnicos
- **SEO optimizado** con metadata, Open Graph y sitemap automático
